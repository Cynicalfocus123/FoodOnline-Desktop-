FoodOnlines TMDHosting cPanel Upload
====================================

1. Login to TMDHosting cPanel.
2. Open File Manager.
3. Go to the live domain folder, usually:
   /home/USERNAME/public_html/
   or:
   /home/USERNAME/foodonlines.com/
4. Upload foodonlines-tmdhosting-cpanel-upload.zip.
5. Extract the ZIP.
6. Confirm these files are directly inside the live folder:
   index.html
   admin.html
   favicon.svg
   .htaccess
   assets/
7. Do not leave the files inside a nested frontend-upload folder.
8. Test the public frontend:
   https://foodonlines.com/
9. Test admin:
   https://foodonlines.com/admin
   https://foodonlines.com/admin.html
10. Test public auth:
   https://foodonlines.com/#login
   https://foodonlines.com/#signup
11. Test API:
   https://www.api.foodonlines.com/api/v1/auth/me
12. If the site shows a white page, check that assets/ exists beside index.html and that JS/CSS files do not return text/html.

Manual login/register test
--------------------------
- Open public site.
- Click Login / Register.
- Test login with a live Laravel account.
- Test register with a new email.
- Confirm successful register appears in admin users if backend supports it.
- Confirm logout works.
- Confirm refresh restores session through /auth/me.

Notes
-----
- This ZIP contains only the public/admin frontend package for cPanel upload.
- The shared production API base remains https://www.api.foodonlines.com/api/v1
- If you deploy inside /public_html/app/ instead of the root domain folder, add:
  RewriteBase /app/
  near the top of .htaccess after RewriteEngine On.
