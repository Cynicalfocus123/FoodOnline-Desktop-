FoodOnlines Admin API Fix Upload
================================

ZIP name
- foodonlines-admin-fix.zip

Upload location
1. Upload foodonlines-admin-fix.zip into the foodonlines.com domain folder.
2. Extract and replace only:
   - index.html
   - admin.html
   - assets/
   - .htaccess

Do not touch
- Do not touch backend folder.
- Do not touch database.
- Do not change Laravel admin password.

Routes to test
- https://foodonlines.com/
- https://foodonlines.com/admin
- https://foodonlines.com/admin.html

API config
- Admin page calls: https://www.api.foodonlines.com/api/v1/admin/login
- API base URL in source: src/lib/runtimeConfig.ts
- API base URL used by build: https://www.api.foodonlines.com/api/v1

API test
curl -i -X POST "https://www.api.foodonlines.com/api/v1/admin/login" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{"email":"info@foodonlines.com","password":"YOUR_PASSWORD"}'

Expected login response
- HTTP 200
- JSON with message, token_type, token, and admin object.

If admin login returns HTML
- API URL is pointing to frontend, not Laravel backend.
- Confirm deployed bundle was replaced.
- Confirm API base URL is https://www.api.foodonlines.com/api/v1.
