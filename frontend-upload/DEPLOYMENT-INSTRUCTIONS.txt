FoodOnlines Hostinger File Manager Upload
=========================================

1. Open Hostinger File Manager for the FoodOnlines domain.
2. Open the live domain root, normally public_html/.
3. Upload the contents of this frontend-upload folder directly into the live root.
4. Keep .htaccess beside index.html and admin.html.
5. Replace stale hashed frontend files under assets/ with this package's files.
6. Confirm these paths exist directly in the live root:
   index.html
   admin.html
   favicon.svg
   .htaccess
   assets/
7. Do not upload the enclosing frontend-upload folder as a nested site directory.
8. Verify the public homepage, product categories, product details, cart, checkout,
   login/signup, and /admin after upload.

Notes
-----
- This folder is the repository's live-deployment mirror of the current dist build.
- The shared production API base remains https://www.api.foodonlines.com/api/v1.
- Product runtime media uses optimized WebP/AVIF files; superseded mockup PNGs
  are intentionally absent.
- If deploying below the domain root, add the matching RewriteBase immediately
  after RewriteEngine On and build with the corresponding VITE_BASE_PATH.
