FoodOnlines Frontend Auth Fix Upload
====================================

ZIP name
- foodonlines-frontend-auth-fix.zip

Upload location
1. Upload foodonlines-frontend-auth-fix.zip into the foodonlines.com domain folder.
2. Extract and replace only:
   - index.html
   - admin.html
   - assets/
   - .htaccess

Do not touch
- Do not touch backend folder.
- Do not touch database.
- Do not change Laravel routes.
- Do not change admin password.

What this fixes
- Removes Continue as Guest controls from public auth flow.
- Keeps Register and Login as main entry flow.
- Keeps signup POST pointed at Laravel API.
- Adds password show/hide buttons to login and signup password fields.
- Makes signup banner match login banner sizing.

Signup API
- Base URL: https://www.api.foodonlines.com/api/v1
- Endpoint: POST /auth/register
- Full URL: https://www.api.foodonlines.com/api/v1/auth/register
- Headers: Accept: application/json, Content-Type: application/json
- Payload keys: account_type, email, first_name, last_name, contact_number, line_id, company_name, password, registered_from
